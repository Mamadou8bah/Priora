# Priora

Private, offline-first personal productivity system.

Priora helps you capture, organise, prioritise, and finish work — with local reminders, smart “what next” recommendations, The Forge (gamification), and Mind Lab (cognitive drills).

- No accounts
- No backend
- No tracking
- All data stays in the browser (IndexedDB) on the user’s device

**Stack:** React · TypeScript · Vite · Tailwind CSS · Zustand · Dexie · Vite PWA · Capacitor (Android)

---

## Requirements

- **Node.js** 20+ (recommended)
- **npm** 10+
- For Android: **Android Studio**, JDK 17+, and an Android device/emulator

## Deploy as a web app / PWA

Priora is a **static SPA**. There is no server API. Build once, host the `dist/` folder on any static host.

### 1. Build

```bash
npm install
npm run build
```

Output directory: **`dist/`**

### 2. Host `dist/`

| Platform | How |
|----------|-----|
| **Vercel** | Import the repo → Framework **Vite** → Build `npm run build` → Output `dist` |
| **Netlify** | Build `npm run build` → Publish `dist` |
| **Cloudflare Pages** | Build `npm run build` → Output `dist` |
| **GitHub Pages** | Build, then publish `dist` (or use an Action). Set Vite `base` if not at domain root. |
| **Any static host** | Upload/sync the contents of `dist/` |

### 3. SPA routing (required)

React Router needs all paths to fall back to `index.html`.

**Vercel** — `vercel.json`:

```json
{
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```

**Netlify** — `public/_redirects` (copied into `dist` on build):

```
/*    /index.html   200
```

**Cloudflare Pages** — `public/_redirects`:

```
/*    /index.html   200
```

**Nginx**:

```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```

### 4. HTTPS & PWA

- Serve over **HTTPS** (required for installable PWA + reliable notifications).
- After deploy, open the site → browser menu → **Install app** / **Add to Home Screen**.
- Service worker + manifest are generated by `vite-plugin-pwa` at build time.

### 5. Custom domain / subdirectory

If you deploy under a path (e.g. `https://user.github.io/priora/`), set the Vite base in `vite.config.ts`:

```ts
export default defineConfig({
  base: '/priora/',
  // ...
})
```

Then rebuild.

## Deploy Android (Capacitor)

App ID: `app.priora.productivity`  
Web assets dir: `dist`

### First time

```bash
npm install
npm run build
npx cap add android   # only if android/ is missing
npx cap sync
npx cap open android
```

Or:

```bash
npm run cap:android
```

### Every update

```bash
npm run cap:sync
# then Build → APK/AAB in Android Studio
```

### Release checklist (Play Store)

1. `npm run build && npx cap sync`
2. Open Android Studio → **Build → Generate Signed Bundle / APK**
3. Use a release keystore (keep it private)
4. Set version code/name in `android/app/build.gradle`
5. Upload the **AAB** to Google Play Console
6. Test notifications/permissions on a real device

Local notifications need runtime permission on modern Android; grant them in-app (Settings → Enable reminders).

## Privacy & data

- Storage: **IndexedDB** (Dexie) in the user’s browser / WebView
- Clearing site data **deletes** tasks and progress
- Users should use **Settings → Export local backup** before switching devices or wiping the browser
- Deploying the static site does **not** sync user data between devices (by design)

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Blank page on refresh of `/tasks` etc. | Add SPA fallback rewrite (see above) |
| PWA won’t install | Need HTTPS + valid manifest; hard-refresh after deploy |
| Old UI after deploy | Hard refresh / unregister service worker once |
| Android shows old web UI | Run `npm run cap:sync` again |
| Build fails on `tsc` | Run `npm install`, Node 20+, then `npm run build` |
